# 原有首页：两阶段预判断与可选执行

## 本次成品目标

- 微雪 ESP32-P4 原板，32 MB Flash；采用项目原版 `postv3` 构建配置。当前 SDK 实际支持 P4 revision **3.1～3.99**，应用镜像头也明确限制为此范围。
- 可另外构建此前 P4 v1.3 旧板的 16 MB 版本：`prev3`、`esp32p4_es-libs`，官方 `app3M_fat9M_16MB` 双 3 MB 应用分区。Flash 容量与芯片修订版是两个独立参数；16 MB 本身不能判断芯片版本。包内 `verification.json` 和镜像头记录对应限制。
- X179 引脚：BODY TX4/RX5、CHASSIS TX2/RX3、PARTY TX26/RX27，均为 500 kbit/s。
- 保留原有中文首页、热点、设置和原有功能处理。在首页增加“换挡建议 · 可选执行”卡片。
- **整份固件仍有原有车控功能，不是之前那个整机 RX-only 诊断程序。新增执行开关默认关闭；关闭时建议模块仍只显示。执行实现见 `GEAR_SHIFT_CONTROL.md`。**

## 无互联网测试

使用原有固件的热点及密码，浏览器打开 `http://192.168.4.1`。网页、样式、字体与脚本均随固件提供，新增模块不访问外部网络。

首页优先显示设备的“已预备 D/R · 踩刹车执行”，并显示数据来源、阻止原因和状态。新候选必须先在松刹时完成预判断；踩住刹车后出现或改变的候选不能执行。每次有效松刹、重踩最多执行一次，最终条件不满足时不会在保持刹车后补发。

参考提供的界面，卡片新增“雷达换挡建议（仅显示）”开关和“本卡片数据来源”选择：

- 关闭时立即清除方向、禁用模拟按钮并停止本卡片的接口轮询；设备的原有 CAN 接收和车控功能不受影响。
- V13/V14 使用独立缓存提前配对，接入与 V12 相同的预备授权器；原有刹车互锁诊断投影保留在旧字段。D/R 含义未独立验证。详见 `VISION_PDR_OBSERVATION.md` 和 `GEAR_SHIFT_CONTROL.md`。
- V12 现已接入真实 CAN 距离规则判断器，在必需状态、新鲜度、独立配对和稳定窗口满足时显示 D/R 候选；否则显示具体原因。车速来源可选，安全带要求可选、速度默认8 km/h、方向盘确认可选，D/R障碍距离阈值可用输入框自定义（1–499cm，默认100cm）；支持两阶段预判断、刹车＋方向盘确认、P挡方向盘确认和彻底切断时速（1–30km/h，默认10）；不计算扫掠路径或认证通道安全。详见 `V12_DISTANCE_RULES.md`。
- V12 卡片内另有“离线规则验证”工具，按本次提供的方法对模拟输入做候选和门控实验；可应用四项测试预设、编辑 JSON、查看逐帧原因和导出结果。它不连接车辆输入，不计算真正的完整扫掠路径，不改变上述实时兼容状态。详见 `V12_OFFLINE_TEST.md`。不接设备时，可直接打开包内 `V12-offline-test.html`。
- 显示开关和来源仍保存到当前浏览器的 localStorage。“实际换挡执行”开关及执行参数写入设备 NVS，默认关闭。浏览器禁止保存时，设置仍可在本次页面使用，并显示保存限制。

安全带要求、0～8 km/h 判断上限、方向盘角度、冷却和距离阈值共同用于预备与执行。彻底切断时速默认 10 km/h，可输入 1～30 km/h，且不能低于判断上限；超限时清空候选、停止候选计算，仅保留必要接收与车速恢复检查。执行开关关闭时这些参数仍可保存到设备。

“离车模拟显示”里的两个按钮只改变当前浏览器的显示，不写入设备，不发送 CAN 请求，十秒后自动恢复实时观察。模拟时卡片明确标记“模拟数据 · 非原车建议”；不连接车辆 CAN 也能用它检查页面效果。

## 真实观察的依据和边界

V13/V14 方向显示旁路观察 CHASSIS 的 `0x118`、`0x145` 以及 PARTY 的 `0x255`、`0x12B`。V12 使用独立的实车距离规则显示候选，并保留原始采集；其范围和局限详见 `V12_DISTANCE_RULES.md`。按用户提供的逆向资料解释成对建议字段；没有独立完成目标车辆协议验证，API 固定报告 `protocolVerified:false`，页面标记为实验性推测。

旧诊断字段的 P/D/R 配对观察：切挡、松刹或输入过期后清除旧配对，等待新会话的两条标准数据帧；长度/字段匹配，且挡位、刹车、建议、方向四份数据均新鲜时显示。刹车必须为有效的驾驶员踩下状态2，apply位仅诊断，不能通过开关关闭此条件；重复旧刹车帧不延长有效期。D/R 属于未验证语义的观察扩展；N/SNA/无效、缺帧、过期、相关控制器恢复/停止或网页断连时清除方向。网页还扣除请求耗时，并设置独立过期计时，不能长时间保留旧方向。

候选模块按参考协议读取探头距离/类别，不验证路线安全。独立的可选执行模块和边沿授权规则见 `GEAR_SHIFT_CONTROL.md`；本地测试通过不代表实车兼容或安全认证。

## 接入与原有逻辑

- `gear_hint_display_pure.h`：仅用于显示的报文解释和过期处理。
- `gear_hint_display_runtime.h`：只接收相关帧的副本，不修改输入；独立锁保护观察状态。
- `gear_hint_display_web.h`：只读 JSON；新增接口为 `GET /api/gear-hint/status` 、`GET /api/gear-hint/v12/raw` 和 `GET /api/gear-hint/v12/decision`；均为 GET。
- `p4_can.h`：新增三个条件编译的旁路观察/失效通知点，不修改原有发送函数和模式选择。
- `tools/gear_hint_ui.html`：独立卡片；模拟完全在浏览器内执行。
- `tools/embed_gear_hint_ui.py`：只插入/更新标记范围内的卡片。
- `tools/gear_hint_baseline.json`：记录增加卡片之前的源文件哈希。构建检查确认原有核心处理源码不变，并确认删去新增接入点和卡片后，其余源码与基线一致。

## 构建与交付

在仓库根目录运行 `python3 build_gear_hint_ui.py`，默认构建 `32 MB / postv3`。此前 P4 v1.3 旧板的 16 MB 版本命令为 `python3 build_gear_hint_ui.py --flash-mb 16 --chip-variant prev3`；仅 Flash 为16 MB 而芯片为新版时用 `--chip-variant postv3`。使用仓库或其父目录 `.toolchain` 的 Arduino CLI、ESP32 3.3.12、对应 P4 SDK 和 RISC-V 工具链。`postv3` SDK 为 Espressif 3.3.12 官方压缩包，SHA-256 为 `b391b8ee6f57fcbdcfbe53f34b4e3f6b8d51f8f09fcd4e5d7304637d919fc309`。

构建检查包括：主机状态边界、页面脚本语法和 DOM、原逻辑保留检查、实际 P4 ELF 引脚、TinyCrypt 链接、内嵌网页与源码一致、应用容量及 ZIP 完整性。浏览器测试以模拟接口验证 D/R/暂无、过期、断连、模拟标记/到期、开关及来源切换、浏览器保存/刷新/禁止保存、V12 不消费 V13/V14 结果以及手机宽度；不代表实车测试。

输出与工作区工具链同级：新版默认 `output/P4CAN-GearShiftControl-v3-Independent-Waveshare-32MB`，旧板16 MB 为 `output/P4CAN-GearShiftControl-v3-Independent-OldP4-16MB`，每个文件夹旁有同名 ZIP，应用镜像文件名附带 `postv3-app.bin` 或 `prev3-app.bin`。32 MB 配套分区为官方 `large_fat_32MB`（双 0x480000 应用槽），16 MB 为 `app3M_fat9M_16MB`（双 0x300000 应用槽）。压缩包包含源码和验证结果。

两个芯片修订版的应用不可混用，也不是整片镜像。刷写前断开车辆 CAN，并确认目标板芯片版本、分区及当前启动槽；不能将应用写到 0 地址，不能据旧设备的地址推定新板地址。本次不打开串口、不刷写设备。

当前 V12 交付以 `V12_DISTANCE_RULES.md` 为准；`V12_LIVE_OBSERVE.md` 保留 R3 采集版的历史说明。


## 三组开关审查

D/R 方向确认和 D/R 角度、P 方向确认和 P 角度、雷达方向确认和雷达确认角分别位于同一边框组内。关闭时保留角度并原生禁用输入，键盘 Tab 不进入禁用输入；开启只解锁本组。三组对 V12 与 V13/V14 均可见。桥接改为手填 SSID/密码，取消扫描；关闭桥接时只禁用桥接的两个输入框。

## D/R 雷达相对确认

D/R 雷达方向确认开启时，雷达距离候选仍优先；踩刹车边沿记录方向盘基准角，页面显示基准角与变化量，达到雷达确认角后立即执行。P 档完全忽略该开关。刹车期间雷达候选丢失时显示 `RADAR_CANDIDATE_LOST`，本脚刹车不降级到手动 D/R 方向。

## 刹车后相对方向盘显示

雷达或原车配对候选有效时沿用“已预备 D/R · 踩刹车执行”。无可执行雷达/原车候选时，P 与 D/R 手动方向盘改为刹车优先：踩下刹车记录基准角，页面显示基准角与当前变化量；达到角度立即显示“角度已确认 · 立即请求 D/R”。D/R 只看相对变化量绝对值，`-120° → -60°` 即达到 60°。同一脚刹车只执行一次，状态显示 `BRAKE_ACTION_USED` 后需松刹重踩并重新记录基准。
